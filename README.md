# 🛒 Telegram Bot: Доска объявлений (Купить / Продать)

Асинхронный Telegram-бот на Python (**aiogram 3.x** + **aiosqlite**), реализующий систему размещения и поиска объявлений через канал и бота.

---

## 📌 Логика работы бота

### 1. Главное меню
Бот предлагает пользователю основные действия:
* **📢 Продать** — разместить объявление
* **🛒 Купить** — найти объявление и связаться с продавцом
* **📋 Мои анкеты** — список созданных объявлений
* **ℹ️ Помощь** — подробная инструкция

---

### 2. Сценарий «Продать»:
1. Пользователь нажимает кнопку **«📢 Продать»** (или отправляет `/sell`).
2. Бот отправляет понятный шаблон анкеты для заполнения:
   * Название товара / услуги
   * Описание
   * Цена
   * Город / Способ передачи
   * Дополнительные детали
3. Клиент заполняет анкету и отправляет её боту (поддерживается **текст** или **фото с описанием**).
4. Бот:
   * Присваивает анкете **уникальный номер** (начиная с `#1001`, `#1002`...).
   * Сохраняет данные в базу данных SQLite.
   * Автоматически публикует красивый пост в Telegram-канал с кнопкой прямого перехода.
   * Отправляет автору подтверждение с номером его анкеты.

---

### 3. Сценарий «Купить»:
1. Пользователь нажимает кнопку **«🛒 Купить»** (или отправляет `/buy`).
2. Бот запрашивает уникальный номер анкеты (например, `1001` или `#1001`).
3. Клиент отправляет номер анкеты.
4. Бот находит анкету в базе и отправляет:
   * Саму анкету (с фотографией, если она была прикреплена).
   * Юзернейм или ссылку на профиль продавца.
   * Инлайн-кнопку **«💬 Написать продавцу»** для перехода в диалог в один клик.
5. Продавец получает уведомление о том, что покупатель заинтересовался его товаром.

> 💡 **Deep Linking:** Под каждым постом в канале есть кнопка *«🛒 Купить / Связаться»*. При нажатии на неё покупатель сразу попадает в диалог с ботом, и бот моментально выдает анкету и контакт продавца без ручного ввода номера!

## 🚀 Установка и запуск

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
cd ВАШ_РЕПОЗИТОРИЙ
```

### Шаг 2. Создание виртуального окружения и установка зависимостей
```bash
python -m venv venv

# Активация на Windows:
venv\Scripts\activate

# Активация на Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### Шаг 3. Настройка переменных окружения
1. Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` в текстовом редакторе и заполните параметры:
   ```env
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
   CHANNEL_ID=@your_channel_name
   DB_NAME=bot.db
   ```
   * `BOT_TOKEN`: Получите у официального бота [@BotFather](https://t.me/BotFather).
   * `CHANNEL_ID`: Юзернейм вашего канала (например, `@my_shop_channel`) или числовой ID (например, `-1001234567890`).
   > ⚠️ **Важно:** Добавьте вашего бота в администраторы канала с правом публикации сообщений (`Post Messages`).

### Шаг 4. Запуск бота
```bash
python main.py
```

Если вы используете Docker и Docker Compose:

## 📁 Структура проекта

```text
├── bot/
│   ├── handlers/
│   │   ├── __init__.py      # Регистрация всех роутеров
│   │   ├── common.py        # /start, /help, /cancel, мои анкеты, deep-link
│   │   ├── seller.py        # Сценарий создания анкеты ("Продать")
│   │   └── buyer.py         # Сценарий поиска анкеты ("Купить")
│   ├── config.py            # Загрузка и валидация конфигурации
│   ├── database.py          # Асинхронная работа с SQLite (aiosqlite)
│   ├── keyboards.py         # Reply и Inline клавиатуры
│   └── states.py            # FSM состояния (aiogram)
├── tests/
│   ├── test_database.py     # Тесты базы данных и инкремента ID
│   └── test_handlers.py     # Тесты роутеров
├── .env.example             # Пример файла окружения
├── .gitignore               # Игнорируемые файлы
├── Dockerfile               # Контейнеризация приложения
├── docker-compose.yml       # Конфигурация запуска Docker Compose
├── main.py                  # Точка входа в приложение
├── pytest.ini               # Конфигурация тестов
├── requirements.txt         # Зависимости Python
└── README.md                # Документация
```
